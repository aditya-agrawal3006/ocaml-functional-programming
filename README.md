# OCaml Functional Programming Projects

Selected OCaml implementations, organized by project and programming concept.

| Project | Topics |
| --- | --- |
| **[SmallC Interpreter](projects/smallc-interpreter/)** | Hand-written lexer, recursive-descent parser, AST evaluation, typed variables, function calls, and control flow |
| [Functional Programming Fundamentals](projects/functional-programming-basics/) | Recursive functions, pattern matching, lists, folds, higher-order functions |
| [Database, Trees & Scheduling](projects/database-trees-scheduling/) | Database query predicates, functional tree operations, greedy interval scheduling |
| [Finite Automata & Regex Engine](projects/finite-automata-regex-engine/) | NFA simulation, DFA construction, regular-expression conversions, and automata visualization |

These projects explore different sides of language implementation, from functional abstractions to finite automata and interpreting a C-like language. Each project has its own documentation, and the implementations use OCaml and Dune.

> Some projects are part of University of Maryland coursework. Some interfaces and specifications were provided by a course. The coursework project implementations have not been independently tested in this portfolio copy.
